# Code of Conduct

This project serves school students, so the bar for conduct is high.

- Be respectful, patient, and welcoming to newcomers.
- No harassment, discrimination, or personal attacks.
- Never share real student data in issues, pull requests, or screenshots.
- Assume good faith and prefer questions over accusations.

Report violations privately to the maintainers. Maintainers may warn, temporarily
block, or permanently ban anyone who breaks these rules. This document adapts the
Contributor Covenant v2.1.
